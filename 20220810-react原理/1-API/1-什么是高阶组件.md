React 高阶组件（Higher-Order Component, HOC）是一种用于复用组件逻辑的技术。HOC 是一个函数，接受一个组件作为参数，返回一个新的组件。它能够增强现有组件的功能，而无需修改组件本身。HOC 的主要应用场景有：

1. **逻辑复用**：当多个组件中有相同的业务逻辑时，HOC 可以提取这些逻辑并在多个组件中共享，避免重复代码。例如，处理用户认证、权限检查、数据获取等场景。

2. **条件渲染**：HOC 可以根据某些条件决定是否渲染某个组件。比如，当用户没有权限时，可以通过 HOC 阻止组件的渲染并显示一个权限不足的提示。

3. **处理副作用**：一些组件可能需要在特定时机执行副作用操作，比如订阅和取消订阅外部数据源。可以通过 HOC 来处理这些生命周期相关的逻辑。

4. **代码拆分和懒加载**：HOC 可以用于实现动态加载组件，只有在需要的时候才加载。例如，当用户访问某个页面时再异步加载该页面的组件。

5. **注入 Props**：HOC 可以通过参数的方式向组件注入额外的 props，例如全局状态、主题信息或配置数据等，增强组件的功能。

6. **访问和修改子组件的生命周期**：在一些特殊场景中，HOC 可以用于扩展或覆盖子组件的生命周期方法，例如在渲染前后做额外的操作。

示例：给一个组件增加权限验证

```jsx
const withAuth = (WrappedComponent) => {
  return class extends React.Component {
    componentDidMount() {
      // 假设有一个 authService 来验证用户身份
      if (!authService.isAuthenticated()) {
        // 如果没有权限，可以跳转到登录页面或展示错误信息
        window.location.href = '/login';
      }
    }

    render() {
      return authService.isAuthenticated() ? <WrappedComponent {...this.props} /> : null;
    }
  };
};

// 使用HOC
const ProtectedPage = withAuth(PageComponent);
```

通过 HOC，可以将权限验证逻辑与组件渲染逻辑分离，复用性和可维护性得到了提升。
