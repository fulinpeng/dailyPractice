`React.memo` 和 `useMemo` 都是优化 React 应用性能的工具，但它们的用法和作用有所不同，适用场景也不同。以下是详细对比：

### 1. **`React.memo`**

`React.memo` 是一个**高阶组件（HOC）**，用于**优化组件重新渲染**的性能。它通过**浅比较（shallow comparison）**来决定是否重新渲染组件。如果 `props` 没有变化，`React.memo` 可以防止组件进行不必要的重新渲染。

#### 用法

```jsx
const MyComponent = React.memo((props) => {
  // 组件逻辑
  return <div>{props.name}</div>;
});
```

在这个例子中，如果 `MyComponent` 的 `props.name` 在父组件的更新中没有变化，React 会跳过 `MyComponent` 的重新渲染。

#### 特点
- **缓存组件的渲染**：`React.memo` 缓存组件的上一次渲染结果。如果 `props` 没有变化，就不会重新渲染组件。
- **浅比较 `props`**：默认情况下，`React.memo` 只会对 `props` 进行浅层比较。如果 `props` 是对象类型，只有引用发生变化时才会触发重新渲染。
- **可自定义比较函数**：可以传入自定义比较函数，进行更复杂的比较逻辑。

#### 示例：自定义比较函数

```jsx
const MyComponent = React.memo((props) => {
  return <div>{props.name}</div>;
}, (prevProps, nextProps) => {
  return prevProps.name === nextProps.name;  // 自定义比较逻辑
});
```

#### 适用场景
- 用于防止**父组件更新**时子组件不必要的重新渲染，特别是在**大型组件树**中效果显著。
- 适合对**纯展示组件**进行优化，减少渲染次数。

### 2. **`useMemo`**

`useMemo` 是一个**React Hook**，用于**缓存计算结果**，防止在每次渲染时重新执行昂贵的计算或对象创建。它在依赖项没有变化时，返回缓存的值，从而避免不必要的计算。

#### 用法

```jsx
const memoizedValue = useMemo(() => {
  // 计算较为昂贵的逻辑
  return computeExpensiveValue(a, b);
}, [a, b]);  // 只有 a 或 b 发生变化时，才重新计算
```

在这个例子中，`computeExpensiveValue(a, b)` 只有在 `a` 或 `b` 发生变化时才会重新计算，否则返回缓存的结果。

#### 特点
- **缓存计算结果**：`useMemo` 用于缓存复杂计算的结果，避免在每次组件渲染时重复执行相同的计算。
- **依赖项控制**：只有当依赖项数组中的值发生变化时，才会重新计算。否则直接返回缓存的结果。
- **减少不必要的重新渲染或重新计算**：对于需要生成对象、数组或执行耗时计算的情况，`useMemo` 可以防止重复执行，从而提升性能。

#### 适用场景
- 用于**避免昂贵计算**，例如：计算大的数组、过滤和排序等操作。
- 用于**防止对象或数组**的引用变化导致子组件不必要的重新渲染。
- 用于缓存**动态生成的值**，例如依赖复杂逻辑生成的对象或数组。

### 3. **区别**

| 特性         | `React.memo`                            | `useMemo`                                      |
|--------------|----------------------------------------|------------------------------------------------|
| **类型**     | 高阶组件 (HOC)                         | React Hook                                     |
| **作用**     | 缓存组件渲染，防止不必要的组件重新渲染   | 缓存计算结果，防止不必要的重新计算               |
| **触发时机** | 当组件 `props` 发生变化时               | 当依赖项数组中的值发生变化时                    |
| **主要优化点**| 避免子组件在父组件重新渲染时不必要的渲染 | 避免昂贵的计算或对象生成                       |
| **使用场景** | 控制组件的渲染优化                     | 控制计算或生成数据的优化                        |
| **依赖项**   | `props` 的变化                         | 手动设置的依赖项（依赖数组）                    |

### 4. **总结**

- **`React.memo`**：适合用来避免子组件在父组件更新时的**不必要重新渲染**。如果一个组件的 `props` 很少变化，或者 `props` 变化的频率不高，使用 `React.memo` 可以有效减少重新渲染次数，从而提升性能。
  
- **`useMemo`**：适合用于避免**昂贵的计算**或避免不必要的对象创建。比如，你在渲染过程中有复杂的计算逻辑，或者生成了大数组、对象等，这些操作本身不涉及组件渲染，但会占用很多计算资源。

**简单的理解：**
- `React.memo` 优化的是**组件重新渲染**。
- `useMemo` 优化的是**计算结果的缓存**。
