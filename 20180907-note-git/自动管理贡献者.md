### 步骤 1：安装 All Contributors CLI
在本地终端中，运行以下命令以安装 All Contributors CLI 工具：
```bash
npm install -g all-contributors-cli
```

### 步骤 2：初始化 All Contributors
进入你的项目文件夹，并运行以下命令来初始化 All Contributors：
```bash
all-contributors init
```
这会在项目的 `README.md` 中添加一个贡献者区块，并生成 `.all-contributorsrc` 配置文件。

### 步骤 3：添加贡献者
要添加贡献者，可以运行以下命令：
```bash
all-contributors add <GitHub用户名> <贡献类型>
```
例如，如果你要添加一位提交代码的贡献者：
```bash
all-contributors add username code
```

**常见的贡献类型**：
- `code`：代码
- `doc`：文档
- `design`：设计
- `bug`：报告 Bug
- `infra`：基础架构
- `test`：测试
- `review`：代码评审

### 步骤 4：更新 README 文件
每次添加或修改贡献者后，运行以下命令来更新 `README.md`：
```bash
all-contributors generate
```

### 步骤 5：将更改推送到 GitHub
完成所有操作后，提交并推送到 GitHub 仓库：
```bash
git add .
git commit -m "Add contributor"
git push origin <branch-name>
```

### 自动化管理贡献者
你可以使用 All Contributors GitHub Bot 来自动管理贡献者。只需将 All Contributors GitHub App 安装到你的仓库，当有人打开 Issue 或 Pull Request 时，可以直接评论“`@all-contributors please add <GitHub用户名> for <贡献类型>`”来自动更新贡献者列表。

这样就可以轻松管理和展示贡献者列表啦！
