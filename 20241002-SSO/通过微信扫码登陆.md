接入微信二维码登录的大致流程包括以下步骤：

### 1. **申请微信开放平台账号和登录权限**
   - 访问[微信开放平台](https://open.weixin.qq.com/)并注册账号。
   - 创建应用并填写基本信息，如应用名称、图标、应用描述等。
   - 申请“微信登录”权限，并设置回调地址用于接收授权完成后的跳转。

### 2. **配置并获取登录授权信息**
   - 在应用管理中找到“开发设置”，获取`AppID`和`AppSecret`，它们用于后续生成二维码并验证用户身份。
   - 配置应用的授权回调域名，确保在微信登录完成后返回到网站对应的回调页面。

### 3. **生成微信登录二维码**
   - 使用微信提供的授权URL格式：`https://open.weixin.qq.com/connect/qrconnect?appid=APPID&redirect_uri=REDIRECT_URI&response_type=code&scope=snsapi_login&state=STATE#wechat_redirect`。
   - 替换 `APPID` 和 `REDIRECT_URI`，`redirect_uri` 应使用 URL 编码。
   - 用户扫描二维码后会被重定向至设置的回调地址，并在 URL 中附带 `code` 和 `state` 参数。

### 4. **通过 code 获取 Access Token**
   - 用户同意登录后，后台通过 `code` 换取 `access_token` 和 `openid`。
   - 向微信的授权服务器发送请求：`https://api.weixin.qq.com/sns/oauth2/access_token?appid=APPID&secret=APPSECRET&code=CODE&grant_type=authorization_code`。
   - 替换 `APPID`、`APPSECRET` 和 `CODE`，获取 `access_token` 和 `openid`（用户唯一标识）。

### 5. **获取用户信息**
   - 拿到 `access_token` 和 `openid` 后，通过 `https://api.weixin.qq.com/sns/userinfo?access_token=ACCESS_TOKEN&openid=OPENID` 请求用户信息。
   - 返回的用户信息包括昵称、头像等基本资料。

### 6. **登录或绑定用户**
   - 根据返回的用户信息，完成本地用户系统的登录或账号绑定。
   - 如果用户是首次扫码登录，可以提示其进行账号绑定或创建新账号。

### 7. **关闭二维码页面或回调登录页面**
   - 在前端检查回调地址返回的结果，如果登录成功，则显示成功消息并完成页面跳转；若失败，显示相应错误信息。

这种登录方式可以用于提升用户体验，但确保在回调中妥善处理 `code` 和 `state` 验证，以防伪造请求。
