要实现后台运行 `node task.js`，使其执行完毕后自动关闭，并在下次 SSH 登录时能够查看其执行状态，可以按照以下步骤操作：

### 1. 使用 `screen` 来运行 `node task.js`

`screen` 是一种虚拟终端工具，适合运行长时间任务，可以随时重新连接查看执行状态。

1. **启动并创建会话**：连接到服务器后，输入以下命令，启动 `screen` 并命名会话。
   ```bash
   screen -S my_task
   ```

2. **运行 Node 任务**：
   ```bash
   node task.js
   ```

3. **分离会话**：按 `Ctrl+A` 然后按 `D` 键分离会话，这样你可以退出 SSH 或进行其他操作，任务会继续在后台运行。

4. **查看执行状态**：下次 SSH 登录后，输入以下命令重新连接并查看状态。
   ```bash
   screen -r my_task
   ```

5. **查看结束状态**：任务完成后会自动关闭会话，可以在 `screen -r my_task` 时验证会话是否还在运行，也可以通过 `screen -ls` 查看所有 screen 会话状态。

要退出一个在 `screen` 中运行的后台任务，可以使用以下方法：

1. **恢复会话**：重新连接到 `screen` 会话，输入 `screen -r task_session`（假设会话名称是 `task_session`），这样就可以进入任务运行的 `screen` 窗口。

2. **停止任务**：进入会话后，直接使用 `Ctrl+C` 终止任务。如果任务持续运行，`Ctrl+C` 会将其立即停止。

3. **关闭会话**：任务结束后，输入 `exit` 退出并关闭 `screen` 会话。此操作会彻底关闭 `screen` 会话，不留后台任务。

如果希望在不进入会话的情况下关闭它，也可以使用 `screen -ls` 查看所有会话的列表并找到会话编号，然后使用 `screen -X -S <会话ID> quit` 命令直接退出。

**总结**：如果任务只是偶尔运行，`screen` 或 `nohup` 更为简洁；如果希望对多任务进行统一管理，`pm2` 会是一个更强大的方案。
