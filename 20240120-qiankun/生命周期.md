在 **qiankun** 微前端框架中，子应用的三个生命周期钩子函数用于管理子应用的加载、渲染和卸载流程。这三个生命周期钩子分别是：`bootstrap`、`mount` 和 `unmount`，它们在子应用被主应用加载和销毁的过程中起到了关键作用。具体功能如下：

### 1. **bootstrap（初始化阶段）**
   - **作用**：当子应用首次被加载时调用，用于执行全局初始化操作。
   - **功能**：通常用于执行一次性的全局资源初始化工作，比如初始化全局状态、配置全局事件监听器、设置全局数据源等。
   - **何时调用**：只会在子应用第一次加载时调用一次。
   - **示例**：
     ```javascript
     export async function bootstrap() {
       console.log('子应用初始化');
       // 一些初始化操作
     }
     ```

### 2. **mount（挂载阶段）**
   - **作用**：当子应用被激活、加载到页面上时调用，负责渲染子应用的具体内容。
   - **功能**：主要用于将子应用的视图渲染到 DOM 中，通常是初始化子应用的组件或页面。例如在 React 或 Vue 中，这个阶段会负责渲染根组件。
   - **何时调用**：每次子应用进入激活状态时都会调用。
   - **示例**：
     ```javascript
     export async function mount(props) {
       console.log('子应用挂载');
       renderApp(props);
     }
     ```

### 3. **unmount（卸载阶段）**
   - **作用**：当子应用从主应用中被卸载时调用，用于清理子应用的资源。
   - **功能**：负责移除子应用的 DOM 元素和事件监听器，清除任何全局的副作用，比如取消订阅、移除全局事件监听等。此阶段确保子应用卸载时不会对主应用或其他子应用产生影响。
   - **何时调用**：每次子应用被卸载时调用。
   - **示例**：
     ```javascript
     export async function unmount() {
       console.log('子应用卸载');
       unmountApp(); // 例如 React 的卸载操作
     }
     ```

### 生命周期钩子的作用总结
这三个生命周期钩子函数的主要目的是帮助子应用在 qiankun 微前端架构中与主应用配合顺畅，确保：
- **资源管理**：确保子应用的资源（如事件监听器、全局状态等）在挂载和卸载时正确管理，避免内存泄漏或冲突。
- **视图渲染**：确保子应用的 UI 能够正确加载和卸载，按需渲染，避免影响主应用和其他子应用。
- **初始化**：保证子应用的全局状态或配置信息能在应用首次启动时正确初始化。
