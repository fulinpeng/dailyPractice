要获取 **FCP**（First Contentful Paint）、**Speed Index** 和 **TTI**（Time to Interactive）等 Web 性能指标，通常会使用浏览器的性能 API，如 **Performance API** 和 **Navigation Timing API**。此外，还可以结合第三方工具来测量这些指标。

### 1. **Performance API**

现代浏览器提供了一个 **Performance API**，通过它可以获取各种与页面加载和渲染相关的详细信息。要获取 **FCP**、**Speed Index** 和 **TTI**，可以使用 `window.performance` 和相关的性能事件。

### 2. **FCP (First Contentful Paint)**

**FCP** 表示从用户开始加载页面到浏览器渲染出任何内容（如文本或图片等）的时间。可以通过 `PerformanceObserver` 来监听 `paint` 事件。

```javascript
if ('PerformanceObserver' in window) {
  const observer = new PerformanceObserver((entryList) => {
    const entries = entryList.getEntries();
    entries.forEach((entry) => {
      if (entry.name === 'first-contentful-paint') {
        console.log('FCP: ' + entry.startTime + 'ms');
      }
    });
  });
  
  observer.observe({ type: 'paint', buffered: true });
}
```

### 3. **Speed Index**

**Speed Index** 是由 WebPageTest 工具引入的性能指标，它衡量的是网页视觉上加载的速度，越低越好。浏览器原生 API 并没有直接暴露 Speed Index，不过可以通过工具或者借助一些计算方法来估算。例如，Google 的 **Lighthouse** 就有计算 Speed Index 的功能。

要通过 Lighthouse 获取 Speed Index：
- 在 **Chrome DevTools** 中，打开 DevTools，选择 "Lighthouse" 标签页。
- 点击 "Generate report"，它会自动为你生成性能报告，并提供 Speed Index。

#### 使用 Lighthouse 来获取 Speed Index（命令行方式）：
```bash
lighthouse <your-url> --output=json --output-path=report.json
```
Lighthouse 输出的 JSON 文件中会包含 `Speed Index` 的值。

### 4. **TTI (Time to Interactive)**

**TTI** 表示从页面加载开始，到页面成为完全互动的时间。这意味着页面加载完成后，用户可以与页面进行交互（点击、滚动、输入等）。要获取 TTI，Google 提供了一个 **Time to Interactive** 的测量工具，通常也通过 **Lighthouse** 工具获取。

可以通过 `PerformanceObserver` 监听 `DOMContentLoaded` 和 `load` 事件来粗略估算 TTI，但要精确获取 TTI，最好使用工具如 **Lighthouse** 或 **WebPageTest**。

```javascript
if ('PerformanceObserver' in window) {
  const observer = new PerformanceObserver((entryList) => {
    const entries = entryList.getEntries();
    entries.forEach((entry) => {
      if (entry.name === 'interactive') {
        console.log('TTI: ' + entry.startTime + 'ms');
      }
    });
  });

  observer.observe({ type: 'navigation', buffered: true });
}
```

### 5. **合并使用 Performance API 和 其他工具**

除了浏览器的 Performance API 外，工具如 **Lighthouse** 和 **WebPageTest** 提供了更加精确的度量指标，尤其是 `Speed Index` 和 `TTI`。

#### 使用 Web Vitals

如果你使用的是现代的 Web 应用，Google 提供的 **Web Vitals** 库也能够轻松地获取 **FCP**、**LCP**（Largest Contentful Paint）、**FID**（First Input Delay）等重要指标：

```bash
npm install web-vitals
```

然后在应用中使用：

```javascript
import { getFCP, getLCP, getFID } from 'web-vitals';

getFCP((metric) => {
  console.log('FCP:', metric.value);
});

getLCP((metric) => {
  console.log('LCP:', metric.value);
});

getFID((metric) => {
  console.log('FID:', metric.value);
});
```

### 总结

1. **FCP** 可以通过监听 `performance.getEntriesByType('paint')` 获取。
2. **Speed Index** 需要借助工具如 **Lighthouse** 或 **WebPageTest** 来获取。
3. **TTI** 可以通过结合 `DOMContentLoaded` 和 `load` 事件来估算，或者通过 **Lighthouse** 来精准获取。
4. 使用 **Web Vitals** 可以方便地获取重要的 Web 性能指标，并在应用中集成实时监控。
