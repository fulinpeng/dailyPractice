在进行懒加载或瀑布流布局时，获取滚动高度是一个关键步骤。常规的获取滚动高度的方法通常是通过 `window.scrollY` 或 `document.documentElement.scrollTop`，但当页面非常复杂或者有多个可滚动区域时，这种方式可能会有性能瓶颈或者处理不精准的情况。

### 优化滚动高度获取的几种方法：

1. **节流（Throttle）或防抖（Debounce）处理**
   滚动事件是一个高频触发的事件，频繁获取滚动高度会影响性能。为了减少不必要的计算，可以通过**节流**或**防抖**来限制滚动事件的频率。

   - **节流**：规定在一定的时间段内，滚动事件只能执行一次。
   - **防抖**：只有在滚动停止之后，才会执行获取高度的操作。

   ```javascript
   // 使用 lodash 的 throttle 或 debounce 进行优化
   import { throttle, debounce } from 'lodash';

   window.addEventListener('scroll', throttle(() => {
     console.log('Scroll Y:', window.scrollY);
   }, 200)); // 每200ms执行一次
   ```

2. **Intersection Observer**
   现代浏览器提供的 `Intersection Observer API` 可以更高效地检测元素是否出现在视口中，避免了手动监听滚动事件并计算位置。这种方法在处理懒加载时非常高效，避免了直接获取滚动高度。

   ```javascript
   const observer = new IntersectionObserver((entries) => {
     entries.forEach(entry => {
       if (entry.isIntersecting) {
         // 元素进入视口时触发加载逻辑
         loadContent();
       }
     });
   });

   const targetElement = document.querySelector('#lazy-load-element');
   observer.observe(targetElement);
   ```

3. **使用 `requestAnimationFrame` 代替直接监听滚动事件**
   使用 `requestAnimationFrame` 可以将滚动事件处理推迟到下一帧渲染时，从而避免阻塞主线程。这样可以提高页面的性能，尤其是在复杂的布局中。

   ```javascript
   let ticking = false;

   window.addEventListener('scroll', function () {
     if (!ticking) {
       window.requestAnimationFrame(function () {
         console.log('Scroll Y:', window.scrollY);
         ticking = false;
       });
       ticking = true;
     }
   });
   ```


### 总结：
- 使用节流或防抖技术减少滚动事件的触发频率，优化性能。
- 尽量使用 `Intersection Observer API` 代替手动计算滚动高度，处理懒加载和瀑布流更高效。
- `requestAnimationFrame` 可以将滚动事件处理延迟到下一帧渲染时，进一步提升性能。
